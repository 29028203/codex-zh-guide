# Codex 做游戏，这 10 个 Agent Skill 够你搭一支开发团队

> 原文链接：[https://www.sz003.com/chajian/2607](https://www.sz003.com/chajian/2607)

<p><a href="https://www.sz003.com/" target="_blank" rel="noopener">Codex</a> Skills 仓库里，游戏开发已经拆出 10 个细分技能，从生成游戏到多人联机，一条完整开发链路上的活都有人接手了。</p>
<p><img loading="lazy" decoding="async" src="https://cdn.laoshoucun.com/web/codex/2026/09/20260902114525_204670.webp" alt="Codex 游戏开发 Skill 排行榜" width="400" height="533"></p>
<p>装机量最高的是 higgsfield-game-generation，26.1K。它从零搭一个能直接打开的浏览器游戏，Sprite、纹理、3D 资产、音乐、音效都由它出，你只管把想法说清楚，素材和代码一起给你。</p>
<p>底层有 game-engine 顶着，游戏循环、物理、碰撞检测、2D 和 3D 渲染这些基础件全归它。11.9K 的下载量放在这，愿意自己从引擎写起的人不多。</p>
<p>OpenAI 官方出的 develop-web-game 走另一条路，不让 Codex 一次性写码，而是写代码、测试、截图、检查、修 Bug、再测试，转成一个迭代循环。1.1K 的体量偏小，好在有官方身份。</p>
<p>玩法设计交给 game-design-theory，玩法循环、玩家体验、关卡、奖励机制都在它手里，1.8K。它要回答的是代码跑通了、游戏为什么不好玩这件事。</p>
<p>game-feel 管打击反馈、粒子效果、屏幕震动、动画、音效、操作反馈，1.3K，把能玩调成玩起来顺手。</p>
<p>联机方向有 multiplayer-game，matchmaking、实时状态同步、tick loop、玩家连接都覆盖，7.1K。</p>
<p>界面是 AI 写游戏的固定短板，功能能跑，样子像半夜赶工。game-ui-design 负责菜单、HUD、按钮、状态栏，2.5K；game-ui-ux 解决响应式布局、安全区域、键盘和手柄导航，1.3K，这两个一般配着用。</p>
<p>3D 网页游戏找 threejs-game-ui-designer，专做 Three.js 项目的 HUD、菜单、Overlay、触控按钮、响应式布局，1.2K，面窄但指得准。</p>
<p>拿不准就先装 game-developer，它按专业游戏开发的流程去落玩法、逻辑、功能，4.5K，属于兜底型。</p>
<p>组合上先装三件套：develop-web-game 管全流程迭代，game-engine 管底层，game-feel 管手感，其余按项目缺什么补什么。</p>
