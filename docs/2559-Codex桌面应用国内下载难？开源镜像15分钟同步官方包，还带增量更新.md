# Codex桌面应用国内下载难？开源镜像15分钟同步官方包，还带增量更新

> 原文链接：[https://www.sz003.com/chajian/2559](https://www.sz003.com/chajian/2559)

<p>一位朋友最近想装 Codex 桌面端，卡在第一步：官方下载要过微软商店和海外 CDN，速度全凭缘分，他挂了一个整晚也没等到安装包落地。最后解围的是我转给他的 GitHub 项目 codex-app-mirror，直连 15 分钟搞定。这项目的逻辑很干净：安装包与官方一字不差，它唯一做的事，是把下载链路换成国内能直连的。仓库如今 2.8k star，上个月仍在更新。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/codex/2026/08/20260825010403_623740.png" alt="镜像下载同步示意图"></p>
<h2>什么都没改，这是它最硬的承诺</h2>
<p>README 里边界写得斩钉截铁：镜像，且只镜像，不构建，不修改，不重打包。Windows 端的包靠微软商店的目录接口拿元数据，macOS 端直接读官方 DMG，Linux 端则用固定公钥去验 OpenAI 软件仓库的签名。上游不动，镜像不动。上游一发新版，整套安装包连同校验和立刻进 GitHub Releases。</p>
<p>同步的勤快程度也不含糊：Cloudflare 定时任务每 15 分钟探一次上游，另设每 6 小时一次的兜底任务。换句话说，官方出新版，镜像最多落后一刻钟。</p>
<h2>速度的机关藏在一条短链里</h2>
<p>下载入口是短链 codexapp.agentsmirror.com，后面由 Cloudflare Worker 根据 IP 归属地自动分路：大陆请求进 S3 副镜像，由中科院高能物理研究所（IHEP）提供。海外请求走 Cloudflare R2。一条链接通吃，不用手动挑节点，就凭这点，体验已经赢过一批要自己切源的镜像站。</p>
<p>各平台的入口记一下：<code>/latest/win-x64</code> 对应 Windows 64 位，<code>/latest/mac-arm64</code> 给 Apple Silicon，Intel Mac 取 <code>/latest/mac-intel</code>，Windows ARM 机器取 <code>/latest/win-arm64</code>，校验和统一放在 <code>/latest/checksums</code>。</p>
<h2>动没动过包，两层证据可查</h2>
<p>用第三方镜像装软件，绕不开那个老疑问：包被动过吗。这个项目交了两层答案：其一，每个 Release 挂着 SHA256SUMS.txt 和 manifest 清单，动手能力强可以自己核。其二，也是更硬的一层，macOS 更新包连 OpenAI 的 EdDSA 签名一并逐字节照搬。签名绑定的是文件内容，镜像与官方字节相同，原签名自然继续有效，镜像方就算想偷改，也造不出合法签名。这层设计我认为是真聪明。</p>
<p>Mac 用户还多一层福利：Sparkle 增量更新源，日常升级只拉差量，不必每次拖完整 DMG。嫌麻烦的另有懒人路线：配套的 Codex App Manager 客户端，一键安装、干净卸载。</p>
<p>收尾两个提醒。其一，Linux 的 Preview 包（DEB/RPM）只出现在 GitHub prerelease，不走 CDN 短链，Linux 用户得自己去 Releases 页翻。其二，项目与 OpenAI 没有隶属关系，MIT 开源，在意出处的，下完核一遍校验和最稳妥。具体安装步骤，站内<a href="https://www.sz003.com/anzhuang" target="_blank" rel="noopener">免费安装</a>指南有现成的。</p>
