# Codex 0.149.0一个版本塞进242个提交：agents任务仪表盘终于来了

> 原文链接：[https://www.sz003.com/codexdt/2554](https://www.sz003.com/codexdt/2554)

<p>上个月我天天过这样的日子：一个终端里挂五个子代理干活，谁跑到哪一步全凭脑子记，想中途插句话又怕打断任务。这周翻到 <strong><a href="https://www.sz003.com/" target="_blank" rel="noopener">Codex</a> 0.149.0</strong> 的更新日志，第一反应就是，总算有人管这事了。</p>
<p>估一个版本的分量，我有个偷懒路子：功能列表先放一边，数提交数。这一版合进了 <strong>242 个提交</strong>，TUI，沙箱，MCP，Guardian 审查系统几条线上都有，是近几个月最厚的正式版，厚到第二天就得发 0.149.1 小修，算是给这顿大餐擦嘴。不过 242 个提交整盘端上来没人吃得下，普通用户真正该记住的就三块：agents 仪表盘，更聪明的 doctor，一批不动声色的安全加固。</p>
<figure><img decoding="async" src="https://cdn.laoshoucun.com/web/codex/2026/08/20260824223136_781087.png" alt="Codex 0.149.0 版本更新概念图" style="max-width:100%;height:auto"></figure>
<h2>agents 仪表盘：三天走三步，真有人在用</h2>
<p>第一天上静态总览，两天后升成交互式任务面板，接着又配了独立的 <code>codex agents</code> 命令和自定义快捷键。三天走三步，这不是顺手为之，有团队真把它当生产力入口打磨。从前并行跑子代理，看进度全凭翻屏，如今一屏收齐。</p>
<p>配套还有个不起眼却救急的功能：正在跑的会话也能排队收新消息。长任务不敢打断、偏偏又想起一件事要交代，这个场景，老用户都熟。</p>
<h2>doctor 五类体检，把问题掐灭在发生前</h2>
<p><code>codex doctor</code> 这回一口气添了五类检查：网络诊断，桌面应用诊断，桌面更新诊断，桌面安全检查，Windows 沙箱诊断。工具一大，&#8221;跑不起来&#8221;的原因就千奇百怪，与其放大家去论坛一个个捞帖子，不如让工具自己先把脉。我一向觉得，这种补基础设施的版本比堆功能更能说明问题：底座稳了，楼才敢往上盖。</p>
<p>模型侧另有一个信号：GPT-5.6 的最大上下文窗口调高了。提交说明里没给数字，方向却明确，长会话撑爆过的人，懂这里的含金量。</p>
<h2>安全那筐活，感知不到才算干对了</h2>
<p>剩下的大头是安全项。Windows 沙箱堵上了 reparse points 绕过。ConPTY 的 DLL 不再从当前目录加载。敏感文件读取改成 symlink-safe。PowerShell 的一条降级路径直接 fail-closed。插件市场添了身份防伪校验。MCP 的 HTTP 重定向被锁死在配置源站内。这些改动上线时没人鼓掌，价值恰恰在于你永远感知不到。</p>
<h2>升不升</h2>
<p>值得升。多代理并行的重度用户更别犹豫，仪表盘这种东西，是要天天摸的。老用户直接更新。新机器拿<a href="https://www.sz003.com/anzhuang" target="_blank" rel="noopener">安装包</a>起步，进阶配置去<a href="https://www.sz003.com/jiaocheng" target="_blank" rel="noopener">教程</a>区翻，都是现成的。至于 0.150 的 alpha。那是下一个故事。</p>
